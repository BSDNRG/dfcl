# dfcl — слой совместимости Darwin/FreeBSD

Запуск выбранного подмножества приложений Darwin/macOS (Mach-O) и
homebrew-гостей PlayStation 4/5 (Orbis ELF) на FreeBSD. Без
Linux-прослойки, без VM macOS, без эмуляции CPU: код гостя исполняется
на физическом процессоре узла FreeBSD.

**Модель распространения (ранний этап):** демо-видео, собранные
бинарники и свидетельства тестовых прогонов — публичны; исходный код
и внутренняя инженерная документация на этом этапе не публикуются.
Каждое публичное утверждение ниже подтверждено воспроизводимым демо
или заархивированным тестовым прогоном — а не обещаниями.

## Подтверждено демо и архивами тестовых прогонов

| Возможность | Свидетельство |
|---|---|
| **Модуль ядра FreeBSD** (`compat_darwin.ko`) | собран и загружен на FreeBSD 14.x; журнал ядра фиксирует путь активации Mach-O ([демо-видео](docs/demo/darwin_m2_exec_demo.mp4)) |
| **Нативное исполнение Mach-O** | статический x86_64 Mach-O-бинарник исполняется на FreeBSD и завершается с кодом 0 — через imgact ядра, без эмуляции ([скриншот результата](docs/demo/darwin_m2_result.png)) |
| **Исполнение Orbis (PS4) ELF** | `orbisrun --exec` запускает homebrew-ELF PS4; guest `write()` печатает «dfcl orbis ok», exit 0 на FreeBSD 14.5 ([демо-видео](docs/demo/o1exec_demo.mp4)) |
| **Исполнение Orbis (PS5) ELF** | ELF-гость PS5 (abiversion 2, база 0x200000000) исполняется нативно на том же хосте ([демо-видео](docs/demo/ps5_exec_demo.mp4)) |
| **Исследование запуска ритейл-ассетов Orbis** | PS4-тайтл доходит до стадии загрузки игровых ассетов с настоящими (предоставленными пользователем) ассетами на FreeBSD — ни игровые, ни какие-либо материалы Sony не распространяются ([демо-видео](docs/demo/deadcells_freebsd_loading_assets.mp4)) |
| **Автоматизированный тестовый набор** | 1807 проверок, 0 падений, чисто под ASan/UBSan — архив каждого прогона с id коммита дерева |
| **Orbis HLE libkernel** | реестр NID на 377 записей, 15 нативных passthrough-шимов (open/read/write/close/…), сквозной файловый цикл протестирован |

Папка демо: [docs/demo/](docs/demo/) — видео, скриншоты и SSH-лог
зафиксированных прогонов.

## Что пока НЕ работает (честно)

- Исполнение Mach-O за пределами статических POSIX-бинарников: dyld,
  libSystem, Objective-C, графика (Metal/CoreGraphics), XPC/launchd.
- Orbis: полная игровая совместимость — GPU (трансляция GNM→Vulkan —
  работа масштаба лет), аудио, контроллеры — отдельные этапы.
- Fat/universal-бинарники, arm64e/PAC — защищённый отказ, не падение.

Roadmap фиксирует порядок работ, а не календарь. Сроки не обещаются.

## Загрузки (скомпилированные бинарники)

Готовые инструменты прилагаются к [Releases](../../releases):
`dfexec` (загрузчик/лаунчер Mach-O), `dfinspect` (диагностика Mach-O),
`orbisrun` (лаунчер Orbis ELF). Сборка: FreeBSD/amd64.

*Бинарники предоставляются для оценки продемонстрированных
возможностей. Модуль ядра FreeBSD (`compat_darwin.ko`) на этом этапе
не распространяется — его сборка требует соответствующего дерева
исходников ядра FreeBSD; демонстрационная установка доступна
партнёрам по запросу.*
